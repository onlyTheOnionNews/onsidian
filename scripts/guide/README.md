# Guide images

Sources for `public/guide/`, used by the Hoppscotch setup guide (`src/bridge-guide.ts`).

- `popup.png`: `popup.html`, the extension's own markup, CSS and icons (MIT, v0.37) with an example address and a highlight.
- `toolbar.png`: `toolbar.html`, an illustration of a Chromium toolbar and its extensions menu.
- `network.png`: a screenshot of Settings → Network in the app.

To redo the first two, run `npm run dev`, open `/scripts/guide/<name>.html` and capture the top of the page.
